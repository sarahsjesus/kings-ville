# King's Ville

```bash
npm install
npm run dev   # http://localhost:3000
```

Controles: botão esquerdo arrasta (pan), botão direito gira, roda do mouse dá zoom.
- Viajantes chegam ao portão: clique neles para recrutar (Fazendeiro, Minerador, Construtor).
- Clique na Sede Real (ou em "Loja Real") para comprar construções, melhorias e bênçãos.
- Melhoria "Vila Próspera" ergue o portão de pedra; "Capital Florescente" ergue o castelo na colina.
